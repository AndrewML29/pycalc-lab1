# Toolkit

Консольный набор утилит на Python для выполнения математических вычислений и конвертации величин.

## Использование

### Калькулятор
Команда для вычисления математических выражений:
```bash
python -m toolkit calc "2 + (3 * 4)"
```
**Особенности:**
* Поддержка целых и вещественных чисел.
* Поддержка базовых операций: `+`, `-`, `*`, `/`, `//`, `%`.
* Поддержка унарных знаков (например, `-5` или `+-5`).
* Поддержка скобок и соблюдение приоритетов операций.
* Игнорирование лишних пробелов.

### Конвертер
Команда для конвертации величин:
```bash
python -m toolkit convert 100 g --from g --to kg
```
**Поддерживаемые группы:**
* **Длина:** `mm`, `cm`, `m`, `km`
* **Масса:** `mg`, `g`, `kg`
* **Температура:** `c` (Цельсий), `f` (Фаренгейт), `k` (Кельвины)

**Особенности:**
* Автоматическая проверка на совместимость единиц (нельзя конвертировать граммы в метры).
* Запрет конвертации температур ниже абсолютного нуля.
* Регистронезависимость единиц измерения.

## Обработка ошибок
В случае возникновения ошибки (неверный синтаксис, деление на ноль, неизвестная единица измерения и т.д.) программа выводит сообщение в `stderr` и завершается с кодом `2`.

## Технические детали
* Реализовано разделение на этапы: токенизация, валидация и вычисления.
* Калькулятор использует алгоритм Шунтинг-ярда для преобразования выражений в обратную польскую запись (RPN).
